# Q: please explain the purpose of this experiment and how each part relates to the other, as well as each parts significance

## Answer

Expanded from original query via graph vocab: [experiment, neural, cellular, growth, genome, conditional, regeneration, ecology, resource, training, model, metrics]. MorphoVoxel tests whether one strictly local genome-conditioned 3D neural cellular automaton can grow multiple stable morphologies from identical seeds and regenerate after damage. The dependency chain is semantic state plus local perception and a shared residual update; 2D validates the mechanism cheaply; single-target 3D isolates the dimensional extension; conditional 3D adds one-hot genomes; specialized models provide the capacity baseline; damage-trained state pools produce the regeneration checkpoint; regeneration evaluation compares standard and damage-trained checkpoints; scaling and interpolation probe generalization; ecology reuses the pretrained conditional checkpoint and gates growth with finite light, water, space, and energy; metrics, saved artifacts, checkpoints, and reports make comparisons reproducible. The current report says the experiment has not yet been run, and smoke presets only validate plumbing, so no hypothesis is yet supported.
